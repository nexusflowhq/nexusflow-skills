# 映射与等价规则

| 源语义 | 目标语义 | 关键检查 |
|---|---|---|
| 物理节点 | 连接节点或合法端口连接 | 同 ID 合并；同坐标不自动合并 |
| 管段 | Pipe 或版本支持的对应组件 | 内径、长度、粗糙度、高程与公式 |
| 定压/定流源 | Source 相应边界 | 类型和符号不变，流股逐源映射 |
| 节点需求 | Load | 基础需求、倍率、分配和曲线只叠加一次 |
| 调压器 | 调压组件 | 控制位置、模式、方向、关闭状态 |
| 截止阀 | 阀门组件 | 阻力定义、开度与关闭泄漏语义 |

目标类名如 Pipe、Source、Load、PressureRegulatingValve、BlockValve 仅作适配线索。字段、枚举数字、端口编号及单位必须从本次目标定义确认。

## 单位与基准

- kPa → MPa 除以 1000；Pa → MPa 除以 1e6；m → km 除以 1000。先查元数据，不能仅凭数值大小决定单位。
- 表压与绝压单独声明；按目标定义转换，不能机械增加或扣除一个大气压。绝对压力参与状态方程。
- 标况体积、工况体积与质量流量不能直接比较。需知道两端标准温度、绝对压力和压缩因子。相同物质的量流率下，Q2 = Q1 × (Z2 T2/P2)/(Z1 T1/P1)，温度用 K。
- 优先使用实际内径；外径减两倍壁厚仅在定义确认后使用。DN 不等于内径。零长连接不以任意短管暗中替代。
- 高程、粗糙度单位、摩阻公式、效率系数、温度、热传递、压缩因子模型与基准条件纳入差异报告。无法映射的热物性不得悄悄采用“常见默认值”。

## 气质

按源流股 ID 关联组分，确认摩尔/体积/质量分数及百分数尺度。组分名建立显式映射；不能丢弃重组分后重新归一化而不说明。仅对已明确为舍入误差的总和偏差归一化并记录原值。质量分数转换需分子量。

## 阀门

保留实际状态、单向限制、监控点和压力控制模式。远端节点控压不自动等价于出口控压；不支持时列为阻断项。源阀门常数、局部阻力 K、Kv、Cv 不互相直接赋值。转换需证明公式、单位和适用工况一致。

用参考流量反求 Kv 属于校准，不属于等价迁移。处于有效控压状态时，增大容量可能不改变流量；需先检查是否全开、限流、倒流或压差不足。禁止为贴合数据自动打开原关闭设备。
