# 验收与诊断

## 结构和结果

核查全部设备数量、物理节点连通分量、管长、几何、单位、摩阻、边界类别和状态。点数来自实际模型，不套用历史工程数量。topology 工具检查端口分组，不检查水力方程或几何。

保存日志、任务状态、实际输入和所需结果。success 不掩盖警告，参数 valid 不代表数值认证通过。缺失结果不作零处理。

分别报告压力绝对/相对误差、流量、各机组状态、性能图范围、旁通/回流、功率、温度、组成和质量平衡。未暴露的内部量不能声称直接验证。近零参考值采用绝对误差，避免无意义百分比。

对比全站流量及各并联分流；局部出口压力吻合不能代表全网。瞬态还核查积分质量平衡、管存、气质前沿及网格/步长敏感性。连续结果和离散事件分别对齐。

误差限来自用户、项目规范或明确标注的暂定建议。没有阈值时只报差异，不自行宣布工程验收通过。

## 故障假设

| 现象 | 先核查 | 避免默认操作 |
|---|---|---|
| 性能图越界 | 工况/标况单位、回流、气质、分流、速度线 | 补假点、强行外推、任意增速 |
| 孤立压力不唯一 | 关闭阀门与停机支路、初场依据 | 打开所有隔离阀并称工况不变 |
| 局部残差小但全局认证失败 | 完整日志、组分耦合、长管状态、控制切换 | 仅引用局部残差宣布成功 |
| 收敛但压力差大 | 几何、摩阻、压比基准、物性、稳态化 | 静默改摩阻或边界凑结果 |
| 组分不变化 | 仿真类型、执行能力、时间区间、介质引用 | 用延长计算代替连续边界功能 |
| 成功无法重现 | 任务所属、输入快照、曲线格式、修订 | 用其他任务结果替代当前任务 |

每次试算记录假设、变更、任务、证据和结论。相同失败无新证据就停止重复，保留备份和诊断结果。

## 报告内容

目标类型；来源/单位；显式值/缺省值/未决值；当前能力缺口；公式与参考点；有意校准；输入与任务标识；结果缺失项；误差与阈值来源；草稿/导出/保存状态；恢复方式。
