# 拓扑和边界

## 节点与端口

以源节点 ID 建立每个元件的端点关联表，再映射目标端口。端口类型和允许连接数读取目标定义；不能假定编号 0/1 在所有组件上都表示入口/出口。

对分支点，优先使用目标支持的显式连接节点。若需调整管道方向，必须同时翻转端点、高程/分段属性和结果流量符号映射。不可随意翻转单向阀或调压器以通过校验。目标不支持该节点连接时阻断并给出差异，不制造串联关系代替分支。

构建关闭设备切分后的连通分量，区分水力连通区与调压器隔开的压力区。检查孤岛、悬空端、重复边、旁通、设备两侧短接和意外循环。没有气源的非零需求孤岛需解决；不是所有缺少定压源的瞬态封闭区都必然无解，应检查初始管存和求解器能力。

## 边界

零需求节点优先为纯连接节点；使用零流量边界时确保全部时间点为零。不得自动注入压力默认值。一个点不能同时强加互相独立的压力与流量约束，除非目标明确支持相关控制器语义。

等价迁移保留原定压/定流类型。多个定压气源可能符合物理运行方式；“每个压力区一个定压平衡源，其余定流”只能作为已授权的边界重构实验，不能作为通用迁移规则。约束上下限与设定值分开，确认它们是报警限值还是会参与求解的硬约束。

## 时间轴

保留时区、起点、终点、采样间隔、插值方式、变化前后取值定义和尾值保持规则。验证时间严格递增、唯一、覆盖仿真区间；缺测不以零替代，插值和外推要有明确策略。调压器设定可固定也可随时间变化，以原始控制曲线为准。

稳态取指定物理时刻的输入，不能把“第一条结果”当作初始边界。瞬态以有效初场启动，保留初场校验。跨软件对比默认相同物理时刻；仅有求解器时间语义证据才调整时间偏移，不通过寻找最小误差人为平移结果。初始时刻是否排除由分析目的决定并显式标注。
