# 压缩机曲线和等效模型

确认源 HEAD/EFFIC/FLOW/SPEED 中扬程与效率类型、流量的参考状态和单位。目标可能是 `[rpm, actual_inlet_flow, absolute_pressure_ratio, efficiency_fraction]`，以实时定义为准。标况流量不得直接填入入口实际流量列。

逐台保留速度线、点数、上下流量边界及插值策略。检查正转速/流量、效率范围、同速线重复流量点。部分试验点不一定代表完整喘振到堵塞区。不同机型不能默认共用曲线；界面可见表格不等于任务实际使用了它。

## 冻结参考工况的近似转换

仅当已确认多变扬程/效率定义，且 H_ref、内部绝对压比 R_ref 和多变指数 n 来自同一运行点时使用：

```
a = (n-1)/n
B = a*H_ref/(R_ref**a-1)
R(H) = (1+a*H/B)**(1/a)
eta_s ≈ (R**a-1)/(R**(a/eta_poly)-1)
```

n>1、H_ref>0、R_ref>1、0<eta_poly≤1。接近1的压比应使用 log/expm1 保持精度。n 不保证等于理想气体比热比，上述效率换算尤其是常指数近似，**不是严格真实气体 BWRS 等价**。参考内部压比不要误用含附件损失的端口压比。

输出记录参考时刻、气质、入口状态及机组来源。停机机组无参考点时列为未决；仅在有依据且符合目标时借用其他参考状态并披露。工具 curve 实现上述近似，不求解状态方程，也不推断参考点。

## 运行逻辑

内部防喘回流与外部停机旁通不同。净管网流量接近零不代表停机或功率为零。核查回流阀、控制迟滞、冷却假设、启动升速、机械效率、止回阀和性能图流量边界。

图越界时优先查单位、气质、边界、分流和回流，不能先补假点、放宽外推或任意增速。某次成功的 Kv、裕度或转速调整不是通用设备参数。

## 定工况等效

以出口压力/压升等替代原设备模型时，保存独立候选和原曲线恢复文件。明确哪些量为输入约束，不能再将其吻合作为独立验证。对并联机组核查分流，小的压力设定差也可能导致较大分流差。

报告停机、阀位、控制方式、效率及分流校准变化。假定效率计算的功率不验证原机器能耗；固定工况模型不能外推到其他气质、速度或瞬态。
