# 单位、组分和拓扑

读取 USEUNITS、METRIC、CUSTODY、STATE、温度模型和运行版本的缺省定义。星号或省略值不能统一当零。报告区分显式值、查证默认值、未决项；本技能不把某一版本的美制标况或等温温度作为通用默认。

| 已确认来源口径 | 目标 | 关系 |
|---|---|---|
| km | m | ×1000 |
| 同单位外径 OD、壁厚 WT | 内径 | OD−2WT，检查正值 |
| kPag | MPag | ÷1000，并核对表压参考压力 |
| 表压 | 绝压 | p_abs=p_gauge+p_reference，同单位 |
| °F | °C | (F−32)×5/9 |
| min | s | ×60 |
| 效率百分数 | 分数 | ÷100 |
| m³/(h·√kPa) 的 Kv | m³/(h·√bar) 的 Kv | ×10，前提是阀门方程与密度口径相同 |

标准体积、当地体积和质量流量不能混用。mass_rate=density_standard×standard_volume_rate，actual_volume_rate=mass_rate/density_actual；小时和秒另行转换。不同标况还涉及 Z，不能只改单位标签。

## 组分

查证 STATE BWRS / BWRS.MOLE 等指令在源版本的含义。确认质量权重后使用：

`x_i=(w_i/M_i)/sum(w_j/M_j)`

分数和百分数都可作权重，但不能混用尺度。检查负数、零总量、重复/缺失组分、正分子量及归一性。区分正构和异构烃；不得把重组分擅自替成甲烷。分子量及来源写进转换依据。

核实目标表究竟接收百分数还是分数，辅助工具同时明确输出两者。同为 BWRS 不证明组分常数、混合规则和物性导数相同；高精度迁移须抽查密度、Z 及相关热力性质。

单组分 RAMP 的“其余原始权重不变、整体再归一”需要从源版本及实际输出证实。证实后才使用相应工具，不以其余分量和不恒为100为由擅自修正源模型。

## 拓扑与管道

- 常数 MOODY/Darcy 摩阻不是粗糙度；Darcy/Fanning 差因子4，先确认定义。
- 保存每个设备的源名称、稳定平台ID、平台端口到源物理节点的映射。
- 对连接边求端口连通分量，核对没有短接不同源节点、没有拆散同一源节点，亦无漏端口。脚本 topology 可辅助核查。
- 核对总管长、内径、壁厚、高程、并联线、局部阻力及流向。维持各设备的物理身份。
- 设定转速不一定是初始实际转速；关闭阀门形成的孤立容积需初场或压力依据，数值锚不是真实库存依据。
- 瞬态另核对管壁弹性、网格、输运格式和热力模型。未公开字段表示接口不能配置该项，不能据此断言内核没有该物理项。
