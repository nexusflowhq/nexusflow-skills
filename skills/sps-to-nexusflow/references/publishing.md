# 开源发布准备

本技能新增说明、脚本及合成测试采用MIT许可证，不包含或重新授权SPS、NexusFlow软件、手册、实际工程数据。不能从其他项目拷贝不明许可代码，再用本包的LICENSE覆盖其原许可。

只打包维护清单内文件：SKILL.md、agents/openai.yaml、references/*.md、明确列出的Python脚本、README.md及LICENSE。排除缓存、备份、工程输入/输出、任务日志、截图、第三方前端源码、二进制与真实配对信息。示例必须独立合成，不能只对真实工程改名。

发布前：

1. 执行离线测试与宿主技能结构验证；检查相对引用完整、没有未替换的脚手架内容。
2. 检查实际压缩包成员及文本，不扫描后又添加其他未审查文件。记录每个文件SHA-256；检查链接/符号链接没有引入包外文件。
3. 搜索真实IP、邮箱、本机绝对路径、工程标识、会话/任务标识、长随机串、凭据赋值和私有URL；保留解释令牌概念的文字，但排除真实值。
4. 秘密扫描是辅助检查，不是无秘密的绝对证明。人工复核文本和来源；测试使用合成数据。
5. 向托管平台推送、创建公开仓库或发版必须在用户实际授权范围内。仅要求“可开源skill”时交付本地包，不自动公开项目。

维护时以最新工具schema重新确认能力。工程中一次失败的变通不得升级为通用默认；新版本支持连续边界或新压缩机模型后，更新能力发现说明并扩展测试，而非保留过时阻断规则。
