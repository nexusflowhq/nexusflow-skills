# MDB 解析

## 读取方式

对原文件计算 SHA-256，使用副本，只读连接。可用匹配位数的 Access ODBC 驱动或可用的 mdbtools；先检查环境，不自动安装驱动。加密压缩包与数据库密码是不同层级，不尝试绕过保护；从用户授权输入获得密码，避免命令日志暴露。

枚举真实表和列，不根据文件名猜测工况。不同版本的表可能不同。常见语义入口包括 Node、Element、GasPipe、GasValve、调压器表、Units、SystemDefaults、流股组分、Profile、ReferenceNodes/ReferenceElements 和各类 Results 表。表名只是发现线索，使用实际主外键与枚举表确认含义。

导出 UTF-8 CSV/JSON，保留原始字段名、数值精度、空值、原始 ID；字符串与数值型 ID 统一但不丢前导零。统计每表行数、唯一键、孤立外键和重复记录。空间坐标仅用于布局，不能代替水力连接。

## 输入、参考与结果

建立三个独立命名空间：

- 输入：管径、长度、粗糙度、状态、控制模式、需求及曲线。
- Reference：参考值、测点身份、时间、单位、质量标记和来源类别。
- Results：上次求解值、结果所属工况、时间和解算状态。

Reference 字段的存在不证明它是实测值；可由用户明确确认其来源，否则称参考值。空值、占位零、真实零流量必须分别记录。不要把结果压力作为源设定值，也不要把管道端部流量重复累计为站点负荷。

对每个派生量保留 table/row/field、转换公式及单位依据。这些溯源记录留在用户输出中，不写回可公开 skill。
