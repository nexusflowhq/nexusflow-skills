# SynergiGas → NexusFlow

输出可追溯、可校验的目标算例及迁移报告。保留源模型语义；把无法等价表达的内容列为差异，不能以默认值补齐后宣称完整等价。

本 skill 不附带模型数据库、现场记录、产品 SDK 或平台凭据。数据库和平台版本不同，需要根据实际表结构与目标组件定义适配；随附脚本是离线校验工具，不是跨版本通用 MDB 转换器。

触发示例：“将我提供的 SynergiGas MDB 模型迁移到 NexusFlow，先检查单位、拓扑和边界条件。”不适用于没有源模型的全新管网设计，也不应在仅请求查看数据库表结构时自动上传或求解。

## 工作流

1. 确认输入模型、工况、目标工作台和任务范围：解析、离线转换、上传或求解。既有授权有效；只请求尚缺的关键选择。连接配置通过环境或运行时参数提供，秘密不写入产物。
2. 解析 MDB 前读 [数据库解析](references/extraction.md)。只读导出表结构、字段、枚举和行数；建立稳定 ID 关联，区分输入、Reference 与历史计算结果。
3. 构建中间模型时读 [映射与等价规则](references/mapping.md)。明确单位、压力基准、气体标况、气质和方向；保留缺失值，生成差异清单。
4. 处理连接和时间曲线时读 [拓扑与边界](references/topology-boundaries.md)。先还原物理节点，再生成目标端口连接；保留原边界类型和关闭设备。
5. 平台操作前读 [目标适配与执行](references/platform.md)。获取目标版本组件定义和模型导出样本，生成 dry-run、映射表和修改清单。仅在已获授权范围内上传和求解。
6. 校核时读 [验收和误差分析](references/validation.md)。先验证输入和稳态初场，再运行瞬态；区分求解失败、输入差异和测量拟合误差。

## 离线辅助工具

Python 3.10+，仅标准库：

```sh
python scripts/audit_model.py normalized.json
python -m unittest discover -s tests -v
```

中间模型格式与工具限制见 [校验数据契约](references/audit-contract.md)。错误退出码为 1，文件/格式错误为 2。工具不访问平台，也不修改输入。

## 交付

- 源表清单、单位和枚举解释；组件及节点映射。
- 目标候选模型、拓扑/边界/阀门审计、未支持功能与所有假设。
- 若已授权执行：上传前后快照、平台验证、求解状态和结果对比。
- 说明版本、输入摘要、时间对齐、误差分母和排除口径；精度结论与收敛结论分别给出。
